# 冰箱食材管家 🧊

一个单页网页工具：录入家里已有的食材，自动推荐能做的菜，临期/过期有提醒，减少浪费。

## 在线使用（微信点开即可）

👉 https://zyb060127-maker.github.io/fridge-ingredient-manager/

> 提示：微信内打开后，如果遇到页面显示异常或按钮无响应，点右上角「···」选择“在浏览器打开”即可。

## 功能

- 添加食材，并设置分类（蔬菜/肉类/禽蛋…）
- 选择存放位置：🧊冷藏 / ❄️冷冻 / 🏠常温
- 自主填写保质期天数（自动算到期日）或直接选到期日
- 临期（3 天内）与已过期自动高亮提醒
- 内置 28 道菜谱，按“现有食材匹配度”智能推荐
- 菜谱库搜索、分类筛选、食材搜索
- 常备调料默认视为已有，可一键关闭
- 数据保存在本机浏览器（localStorage），支持导出/导入 JSON 备份

## 本地使用

直接下载 `index.html`，用浏览器打开即可，无需联网、无需注册。
